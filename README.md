# Tailored-Reporting-with-CatC
This script is written in Python and requires a few packages. Right now it is executed with python3 and consists simply of 2 files, the main PRSNT file, and the AP file.
Both must be in the same folder.
The script requires the CatC IP, a CatC Account and access to these resources.
It will ask for that and does not store local passwords for security reasons. 
You can specify the SITE with --
You can also chose a duration (in hours, days)
Call with:
python "nameofmainscript.py" (add to it --site if you want a specific site)
Screen captures are also provided here as sample running flows.
